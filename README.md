## Языковые модели на трансформере: свой маленький GPT, кодировщик BERT и его дообучение

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ExPl0i/AI-10-NLP-Language-models/blob/main/%D0%9F%D0%A0-%D0%AF%D0%B7%D1%8B%D0%BA%D0%BE%D0%B2%D1%8B%D0%B5%20%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D0%B8.ipynb)

Четвертое занятие Темы 2 «Применение искусственных нейронных сетей» курса «Искусственный интеллект» для 10 класса. Из блоков трансформера, собранных на занятии Т2.Б1.3, ученики собирают две языковые модели. Первая – свой маленький GPT (только декодер с причинной маской), который учится на корпусе русской классики с токенизатором BPE из Т2.Б1.1 и пишет прозу в духе XIX века. Вторая – готовый кодировщик rubert-tiny2 (только кодировщик, без маски): ученики получают векторы фраз, строят смысловой поиск и дообучают кодировщик определять намерение водителя. Сохраненный классификатор намерений – третья часть голосового помощника, его подключают на занятии Т2.Б2.5.

## Теория (презентация)

1. **Три семейства.** Один блок трансформера, три модели: только декодер (GPT, Qwen, LLaMA), только кодировщик (BERT, rubert-tiny2), кодировщик и декодер (T5, Whisper); перекрестное внимание.
2. **Свой маленький GPT.** Предсказание следующего токена и сдвиг цели на один токен; перплексия $e^{L}$ и биты на символ; устройство модели, общие веса эмбеддингов и выходного слоя; эталонное обучение; генерация и температура.
3. **Кодировщик BERT.** Маскированное моделирование, служебный токен [CLS]; модель rubert-tiny2; смысловой поиск по векторам фраз.
4. **Дообучение.** Голова на векторе [CLS], маленький шаг обучения; шаблонные обучающие и живые тестовые фразы; матрица ошибок, F-мера и макро-F-мера.
5. **Практика.** Пять заданий.

## Практическая работа

| Задание | Что пишем | Главный результат |
| --- | --- | --- |
| Г1 | `GPT`, `get_batch`, шаг обучения | 921 344 параметров в легком режиме; потери на проверке падают с 6,3 до 3,10; контрольные точки переживают отключение сеанса |
| Г2 | `generate`, `perplexity`, `bits_per_char` | тексты при температуре 0,5, 1 и 1,5; перплексия около 22 против 124 у частотной модели; сравнение с символьной LSTM |
| Г3 | `embed`, `search` | векторы фраз из 312 чисел длины 1; смысловой поиск без общих слов |
| Г4 | `train_classifier` | дообученный классификатор намерений в папке `intent_classifier` |
| Г5 | `confusion`, `f1_per_class` | матрица ошибок на живых фразах, сравнение с TF-IDF (макро-F-мера 0,819), разбор ошибок |

Задания повышенной сложности: замороженный кодировщик, шестое намерение по ближайшему среднему вектору без обучения, GPT на символах.

**Два режима** выбираются в первой ячейке ноутбука. Легкий – для компьютеров аудитории: словарь 1000, 4 блока по 128 чисел, окно 64 токена, 1500 шагов; вместо обучения можно загрузить готовые веса (`SKIP_TRAINING = True`). Полный – для Colab с видеокартой: словарь 2000, 6 блоков по 384 числа, окно 256 токенов, 2000 шагов. Контрольные точки сохраняются каждые 250 шагов в папку `checkpoints`, в Colab – на Google Диск (`USE_DRIVE = True`), и обучение продолжается с последней точки после перезапуска.

**Своя выборка фраз.** Если рядом с ноутбуком лежит файл `intents.csv` из домашнего задания Т2.Б1.3 (столбцы `text` и `intent`), классификатор учится на нем, иначе – на запасном наборе.

## Подготовка аудитории

На компьютере с интернетом выполнить `python prepare_data.py` и скопировать папку репозитория вместе с появившейся папкой `models/rubert-tiny2` на компьютеры аудитории.
